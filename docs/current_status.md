# Current Development Status

**Last reviewed:** 2026-10-22

This document is intentionally concise so it can be updated as evidence becomes available. Planned functions must not be moved into the completed category without implementation and test records.

## Existing progress

- The farmer's handheld base-unit firmware has been written.
- Base-unit hardware setup and integration are in progress.
- The overall VerdantIQ multifunctional agricultural rover architecture is being developed.
- The preliminary hardware design and editable BOM are being prepared.
- The Nordic nRF54LM20 DK is intended to serve as the rover's dedicated embedded controller, but its complete integration is not yet established in this repository.

## Planned work

- Finalise the hardware architecture and BOM.
- Set up and validate the Nordic development environment.
- Implement sensor acquisition and measurement validation.
- Establish Bluetooth communication with compatible distributed sensor nodes.
- Develop equipment-health monitoring and abnormal-condition alerts.
- Integrate the Nordic controller with the ESP32.
- Develop and validate the rover's agricultural functions, including environmental monitoring, precision irrigation, crop imaging, controlled pesticide application, and night-patrol sensing.
- Test the integrated system and measure sustainability outcomes.

## Not yet claimed

- The base-unit firmware is not included in this repository at this stage.
- Base-unit firmware testing is not claimed without test evidence.
- Base-unit hardware assembly is not claimed as complete.
- Rover operation, field validation, model accuracy, animal-detection performance, water savings, pesticide reduction, and failure prediction are not claimed as demonstrated.
- No component is marked purchased or assembled in the preliminary BOM without evidence.

## Future Update

When progress is made, this document will be updated with:

- Date and short change description.
- Hardware or firmware revision involved.
- Test setup and measured result.
- Known limitations, failures, and next action.
